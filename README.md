# 🔭 Спектр звезды с веб-камеры

Streamlit-сайт: строит спектр звезды по снимку с камеры (телескоп + дифракционная решётка),
калибрует его в нанометры и сравнивает с данными SIMBAD: спектральным классом, ожидаемыми линиями
и кривой Планка.

## Возможности
- снимок прямо с камеры в браузере, загрузка нескольких снимков или видео (кадры усредняются);
- автоматический поиск полосы спектра и вычитание фона неба;
- калибровка по нулевому порядку и дисперсии или по двум известным линиям;
- данные о звезде из SIMBAD: класс, блеск V, координаты, оценка Teff;
- линии, ожидаемые для этого класса (H, He, Ca, Na, Mg, TiO), и полосы O₂ атмосферы;
- скачивание спектра в CSV и PNG;
- **база из 30 известных звёзд** (Солнце, Сириус, Вега, Бетельгейзе, Ригель, VY CMa …) с параметрами и спектрами-шаблонами;
  сравнение с эталоном и автоматический подбор спектрального класса;
- **3D-звезда:** выбранная звезда в её настоящем цвете (спектр → CIE 1931 → sRGB),
  рядом Солнце в том же масштабе и «радуга» её спектра с линиями поглощения.

## Структура
| Файл | Что внутри |
|---|---|
| `app.py` | главная страница: снимок → спектр → сравнение |
| `pages/1_📚_База_звёзд.py` | каталог и графики спектров |
| `pages/2_🌟_3D_звезда.py` | 3D-вид звезды (three.js) |
| `spectrum_core.py` | обработка кадра, калибровка, SIMBAD |
| `star_db.py` | каталог, модельные спектры, подбор класса |
| `star_color.py` | расчёт видимого цвета по спектру |
| `data/stars.csv` | каталог звёзд — можно дополнять |
| `data/templates.csv` | все спектры одной таблицей (`python build_database.py`) |
| `data/observed/<id>.csv` | сюда можно положить реальные спектры: они заменят модель |

Спектры в базе — модельные: кривая Планка для Teff и линии и полосы, характерные для класса.
Их хватает для подбора класса при разрешении веб-камеры. Для точной работы замените их
реальными спектрами (MILES, ELODIE, Pickles 1998).

## Запуск на своём компьютере
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация в Streamlit Community Cloud
1. Загрузите эти файлы в репозиторий на GitHub.
2. Откройте https://share.streamlit.io, войдите через GitHub и нажмите **Create app**.
3. Выберите репозиторий, ветку `main`, файл `app.py` и нажмите **Deploy**.
